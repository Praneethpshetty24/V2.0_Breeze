# Breeze - A Share Funding App

Breeze is a powerful and user-friendly app designed to simplify share funding and investment tracking. Whether you're a seasoned investor or just starting, Breeze helps you stay informed, manage investments, and connect with fellow investors.

## 🚀 Features

- **📈 Trending Insights** – Displays the most bought and most liked stocks on the home screen.
- **🏦 Funding Organization Listings** – View and invest in listed organization stocks.
- **🎯 Portfolio Tracking** – Set and monitor dedicated investment targets.
- **👤 User Profile & Achievements** – Track progress with personalized achievements.
- **🤖 AI Chat Assistant** – Integrated Gemini API for real-time stock-related queries.
- **📊 Order History & Analysis** – Generate insightful charts with Chart.js.
- **💬 Global & Group Chat** – Connect with investors and discuss market trends.
- **📧 Email Notifications** – Receive stock purchase confirmations via Nodemailer.
- **💳 Secure Payments** – Powered by Stripe for seamless transactions.

## 🛠️ Tech Stack

- **Backend:** NestJS, Supabase, Firebase, MongoDB
- **Frontend:** React, Next.js
- **AI Integration:** Gemini API
- **Payments:** Stripe
- **Charts & Analysis:** Chart.js
- **Notifications:** Nodemailer
